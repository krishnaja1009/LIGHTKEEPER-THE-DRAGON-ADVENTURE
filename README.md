🐉 LIGHTKEEPER – THE DRAGON ADVENTURE 🌌

1. Project Information

Project Name: LIGHTKEEPER – Dragon Adventure
Project Type: 2D Fantasy Adventure Game
Programming Language: Python
Game Library: Pygame
Project Category: Game Development

LIGHTKEEPER is a fantasy adventure game in which players control a brave dragon and explore a magical kingdom. The game combines exciting challenges, magical powers, rewards, and boss battles to create an entertaining gaming experience.

2. Game Features

- 🐉 Dragon character with fire-breathing power.
- 🪙 Coins and unlockable dragon skins.
- 🌀 Magic portal and bonus world.
- 🛡️ Shield power to protect the dragon.
- 🌩️ Moving obstacles and challenges.
- 🏰 Easy, Medium, and Hard levels.
- 👑 Exciting final Dragon Boss battle.
- 🌌 Beautiful background with moving stars and houses.

3. How to Play

1. Start the game and choose your difficulty level.
2. Use the keyboard controls to move the dragon.
3. Avoid obstacles and collect coins.
4. Use special powers to overcome challenges.
5. Enter the magic portal to explore the bonus world.
6. Fight the Dragon Boss and try to win the game.
7. Collect rewards and unlock different dragon skins.

4. Objective of the Game

The main objective of LIGHTKEEPER is to guide the dragon through different levels, collect coins, avoid obstacles, use magical abilities, and defeat the final boss. The player must complete challenges, protect the dragon, and bring light back to the magical kingdom.

5. Technologies Used

- Python: Used as the main programming language.
- Pygame: Used to create the game screen, characters, movements, animations, and gameplay.
- Random Module: Used to generate random obstacles and game elements.

6. Installation and Setup

Follow these steps to install and run the game:

1. Install Python on your computer.

2. Open the terminal or command prompt.

3. Install Pygame using the command:
   
   "pip install pygame"

4. Open a Python editor such as IDLE or VS Code.

5. Create a new Python file named "lightkeeper.py".

6. Copy and paste the game source code into the file.

7. Save the file and run the program.

Note: The game requires a Pygame-supported environment to run properly.
